# Gen Z Hub

A mobile-friendly drama, movie, and web series tracker website.

## Features
- Add dramas
- Search dramas
- Delete dramas
- Mark watched / watching
- Open detail page
- Trailer support
- Dark pine-green theme

## Files
- index.html
- styles.css
- app.js
- details.html
- details.js

## Run
Open `index.html` in a browser.
